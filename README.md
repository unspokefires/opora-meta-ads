# Політична реклама Meta: автоматичний збір даних

Репозиторій щодня забирає з Ad Library API політичну рекламу, показану в Україні, зберігає сирі дані в архіві й оновлює Google-таблицю, на якій побудовано дашборд у Data Studio. Код запускається автоматично в GitHub Actions; власний сервер не потрібен.

## Як це влаштовано

Збір іде двома каналами. **Канал пошуку** працює щодня: він забирає всю політичну рекламу, показану в Україні за останні 30 днів, і цим оновлює витрати оголошень, які ще тривають. **Канал сторінок** вмикається щопонеділка: він бере ID рекламодавців зі звіту Ad Library Report, що лежить у репозиторії, і забирає їхні оголошення напряму. Його головне завдання — перевірка повноти: у вкладці «перевірка» видно, скільки оголошень знайшов лише цей канал.

Сирі відповіді API зберігаються в папці `data/raw`, по файлу на кожен день початку показу. Це власний архів ОПОРИ: Meta видаляє оголошення з бібліотеки через сім років, а тут вони лишаться. Курси НБУ кешуються у файлі `data/nbu_rates.json`.

## Файли

`collect.py` — скрипт збору; на початку файлу є блок «НАЛАШТУВАННЯ» з параметрами, які можна змінювати без знання Python.
`.github/workflows/collect.yml` — розклад і порядок запуску.
`requirements.txt` — перелік бібліотек.
`FacebookAdLibraryReport_…zip` — звіт Meta, з якого береться список рекламодавців. Скрипт сам знаходить найновіший звіт за датою в назві.

## Секрети (Settings → Secrets and variables → Actions)

`META_TOKEN` — довгостроковий токен Meta (діє приблизно 60 днів).
`GOOGLE_CREDENTIALS` — повний вміст JSON-ключа сервісного акаунта Google.
`SHEET_URL` — посилання на Google-таблицю. Таблиця має бути відкрита на редагування для адреси сервісного акаунта (`client_email` з ключа).

## Перший запуск

Відкрийте вкладку **Actions**, оберіть «Збір політичної реклами Meta» → **Run workflow**. Для першого запуску в полі «Канал сторінок» варто вказати `no`. Під час першого запуску скрипт дозавантажує всю рекламу з дати `BACKFILL_FROM` (за замовчуванням 1 січня 2026 року), тож він може тривати довше за звичайний.

## Щоденна робота

Нічого робити не потрібно. Якщо запуск завершиться з помилкою, GitHub надішле лист. Стан останнього запуску видно у вкладці таблиці «перевірка»: рядок «Статус» має містити `OK`.

## Коли прийшов лист про помилку

Найчастіша причина — сплив токен Meta. У журналі запуску (Actions → невдалий запуск → крок «Збір і запис у таблицю») тоді буде повідомлення про недійсний токен. Що зробити:

1. У Graph API Explorer згенеруйте новий токен (застосунок проєкту, дозвіл `ads_read`).
2. У developers.facebook.com/tools/debug/accesstoken вставте його, натисніть Debug, потім Extend Access Token.
3. Оновіть секрет `META_TOKEN` у налаштуваннях репозиторію.
4. Запустіть збір вручну (Actions → Run workflow), щоб не чекати наступного дня.

Під час збою таблиця не змінюється: у ній лишаються дані попереднього вдалого запуску. Пропущені дні підхоплюються автоматично, бо щоденний пошук охоплює 30 днів.

## Оновлення звіту Meta

Раз на місяць завантажте свіжий звіт для України на facebook.com/ads/library/report (найкраще за останні 30 днів) і додайте zip-файл у репозиторій через Add file → Upload files. Старі звіти можна не видаляти. Звіт завантажується вручну свідомо: автоматичне вивантаження звіту суперечило б умовам Meta.

## Вкладки таблиці

«перевірка» — стан останнього запуску й контроль якості.
«оголошення» — одне оголошення в рядку, з оцінками витрат у валюті оголошення, гривнях і доларах.
«регіони» — витрати й покази за днем, сторінкою та областю; джерело для мапи. Усі покази за межами України (або з нерозпізнаною назвою регіону) зведено в рядок з кодом `OUT`.
«сторінки» — підсумки за рекламодавцями разом із даними звіту Meta.
«відповідність_регіонів» — як назви регіонів від Meta зіставлено з кодами областей; угорі — зіставлені, нижче — найчастіші незіставлені.
«звіт_meta» — звіт Ad Library Report, зведений за сторінками.
«атрибуція» — ручна довідкова таблиця. Скрипт лише дописує туди нові сторінки й ніколи не змінює заповнені рядки. Значення колонок «актор» і «тип_актора» автоматично підтягуються в інші вкладки під час наступного запуску.

## Методологічні застереження

Meta подає витрати й покази діапазонами. Оцінка — середина діапазону, а для найвищого діапазону без верхньої межі — нижня межа; обидві межі збережено у вкладці «оголошення».

Витрати оголошення — за весь час його показу і прив'язані до дати початку показу.

Регіональні витрати — оцінка: витрати оголошення, помножені на частку його показів в області.

Перерахунок у гривні й долари зроблено за офіційним курсом НБУ на дату початку показу (якщо курсу на цю дату немає — за найближчим попереднім днем).

Позначка `has_disclaimer` розрізняє рекламу з дисклеймером і без нього. Вона не тотожна поділу на українських та іноземних рекламодавців: без дисклеймера йде і частина реклами українських сторінок, і реклама іноземних рекламодавців, що досягла України.

API не гарантує повноти відповіді, тому вкладка «перевірка» показує, скільки оголошень знайшов лише канал сторінок.

## Обмеження, які варто переглянути згодом

Архів у репозиторії зростає приблизно на кілька сотень мегабайт на рік. Google-таблиця має ліміт 10 мільйонів клітинок. Коли даних стане багато, сховище варто перенести в BigQuery; дашборд у Data Studio підключається до нього так само.
