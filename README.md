# Політична реклама Meta: автоматичний збір даних

Репозиторій щодня забирає з Ad Library API політичну рекламу, показану в Україні, зберігає сирі дані в архіві, оновлює робочу Google-таблицю й публікує сторінку дашборду. Код запускається в GitHub Actions; власний сервер не потрібен.

## Як це влаштовано

Збір іде двома каналами. **Канал пошуку** працює щодня й забирає рекламу, показану за останні 30 днів; так оновлюються й витрати оголошень, які ще тривають. **Канал сторінок** вмикається щопонеділка: він бере ID рекламодавців зі звіту Ad Library Report, що лежить у репозиторії, і забирає їхні оголошення напряму, щоб перевірити повноту першого каналу.

**Архів** — це сирі відповіді API, по файлу на кожен день початку показу. Він лежить в окремій гілці репозиторію `archive`, яка зберігає лише останній стан без історії змін, тож репозиторій не розростається від щоденних оновлень. Meta видаляє оголошення з бібліотеки через сім років, а в архіві ОПОРИ вони лишаються. У тій самій гілці зберігаються кеш курсів НБУ (`nbu_rates.json`), перелік повністю завантажених місяців (`coverage.json`) і час останнього вдалого збору.

Скрипти обробляють архів файл за файлом і не тримають усі оголошення в пам'яті, тому працюють і з сотнями тисяч оголошень.

## Спільний диск ОПОРИ

Після кожного запуску `sync_drive.py` вивантажує на спільний диск організації повну копію архіву (по файлу JSON Lines на місяць у папці `архів_jsonl`) і таблиці для локального аналізу в папці `таблиці_csv`: оголошення й регіони окремо за кожен рік, а також підсумки за рекламодавцями. Вивантажуються лише файли, що змінилися. Опис полів лежить на диску у файлі `ПРОЧИТАЙ_МЕНЕ.txt`. Сервісний акаунт має бути доданий до спільного диска з роллю «Менеджер вмісту»; ідентифікатор диска задано в рядку `DRIVE_ID` файлу `.github/workflows/collect.yml`.

## Файли

`collect.py` — збір, архів і Google-таблиця; на початку файлу є блок «НАЛАШТУВАННЯ» з параметрами, які можна змінювати без знання Python.
`build_site.py`, `site_template.html`, `ukraine_map.json` — побудова публічної сторінки.
`sync_drive.py` — вивантаження архіву й CSV-таблиць на спільний диск ОПОРИ.
`.github/workflows/collect.yml` — розклад і порядок запуску.
`requirements.txt` — перелік бібліотек.
`FacebookAdLibraryReport_…zip` — звіт Meta зі списком рекламодавців; скрипт сам бере найновіший за датою в назві.

## Секрети (Settings → Secrets and variables → Actions)

`META_TOKEN` — довгостроковий токен Meta.
`GOOGLE_CREDENTIALS` — повний вміст JSON-ключа сервісного акаунта Google.
`SHEET_URL` — посилання на Google-таблицю (відкрита на редагування для адреси сервісного акаунта).
`SITE_TOKEN` — токен GitHub для публікації сторінки в публічному репозиторії.

## Дозавантаження історії

Ручний запуск (Actions → «Збір політичної реклами Meta» → Run workflow) із заповненими полями «Початок періоду» і «Кінець періоду» забирає рекламу за цей період помісячно. Завершені місяці записуються в `coverage.json`, тож повторний запуск із тим самим періодом пропускає вже завантажене. Якщо запуск не встигає за відведений час (параметр `TIME_BUDGET_MIN`), він зупиняється між місяцями, позначає статус «НЕПОВНО», і достатньо запустити його ще раз із тими самими датами.

Дозавантажувати варто **від новіших років до старіших** (2025, потім 2024 і так далі до 2019): сторінка показує дані лише від того місяця, з якого архів повний без пропусків до сьогодні, і розширюється в минуле в міру дозавантаження.

## Щоденна робота

Нічого робити не потрібно. Якщо запуск завершиться з помилкою, GitHub надішле лист. Стан останнього запуску видно у вкладці таблиці «перевірка»: рядок «Статус» має містити `OK`.

## Коли прийшов лист про помилку

Найчастіша причина — недійсний токен Meta. Токен анулюється, коли він спливає (приблизно через 60 днів), а також **після зміни пароля Facebook, виходу з акаунта на всіх пристроях чи скидання сесій з міркувань безпеки**. Що зробити:

1. У Graph API Explorer згенеруйте новий токен (застосунок проєкту, дозвіл `ads_read`).
2. На developers.facebook.com/tools/debug/accesstoken вставте його, натисніть Debug, потім Extend Access Token.
3. Оновіть секрет `META_TOKEN` у налаштуваннях репозиторію.
4. Запустіть збір вручну (Actions → Run workflow).

Під час збою таблиця й сторінка не змінюються. Пропущені дні підхоплюються автоматично, бо щоденний пошук охоплює 30 днів.

Токен `SITE_TOKEN` теж має термін дії: коли він спливе, збір працюватиме далі, а сторінка перестане оновлюватися, доки ви не створите новий токен і не оновите секрет.

## Оновлення звіту Meta

Раз на місяць завантажте свіжий звіт для України на facebook.com/ads/library/report (найкраще за останні 30 днів) і додайте zip-файл у репозиторій через Add file → Upload files. Звіт завантажується вручну свідомо: автоматичне вивантаження суперечило б умовам Meta.

## Google-таблиця

Вкладки «оголошення» і «регіони» містять дані за останні 12 місяців (параметр `SHEETS_MONTHS`): на всю історію не вистачило б ліміту Google у 10 мільйонів клітинок. Вкладки «сторінки», «відповідність_регіонів» і показники «перевірки» рахуються за весь архів.

«перевірка» — стан останнього запуску й контроль якості.
«оголошення» — одне оголошення в рядку, з оцінками витрат у валюті оголошення, гривнях і доларах.
«регіони» — витрати й покази за тижнем, сторінкою та областю. Покази за межами України зведено в рядок `OUT`, покази з невідомим регіоном — у рядок `UNK`.
«сторінки» — підсумки за рекламодавцями за весь архів разом із даними звіту Meta.
«відповідність_регіонів» — як назви регіонів від Meta зіставлено з кодами областей.
«звіт_meta» — звіт Ad Library Report, зведений за сторінками.
«атрибуція» — ручна довідкова таблиця. Скрипт лише дописує туди нові сторінки й ніколи не змінює заповнені рядки; значення «актор» і «тип_актора» підтягуються в інші вкладки під час наступного запуску.

## Публічна сторінка

`build_site.py` зводить архів за місяцями й публікує сторінку в окремому публічному репозиторії (рядок `SITE_REPO` у `.github/workflows/collect.yml`). Основний репозиторій з кодом і архівом лишається приватним. Дані сторінки розбиті на частини: основні зведення вантажаться одразу, а деталізація за регіоном чи рекламодавцем — лише коли користувач їх обирає. Межі областей — Natural Earth (суспільне надбання); Крим і Севастополь показано як частину України.

## Методологічні застереження

Meta подає витрати й покази діапазонами. Оцінка — середина діапазону, а для найвищого діапазону без верхньої межі — нижня межа; обидві межі збережено у вкладці «оголошення». Витрати оголошення — за весь час його показу і прив'язані до дати початку показу. Регіональні витрати — оцінка: витрати оголошення, помножені на частку його показів в області. Перерахунок у гривні й долари зроблено за офіційним курсом НБУ на дату початку показу (якщо курсу немає — за найближчим попереднім днем).

Позначка `has_disclaimer` розрізняє рекламу з дисклеймером і без нього. Вона не тотожна поділу на українських та іноземних рекламодавців: без дисклеймера йде і частина реклами українських сторінок, і реклама іноземних рекламодавців, що досягла України.

API не гарантує повноти відповіді, тому вкладка «перевірка» показує, скільки оголошень знайшов лише канал сторінок.
